# 梅林初号机 - AFK Journey 自动化脚本

一个用于 AFK Journey（剑与远征：启程）的自动化脚本工具。

## 功能列表

| 功能 | 说明 |
|------|------|
| 登录 | 自动登录游戏 |
| 仓库管理 | 手动勾选英雄练度，推图爬塔用 |
| 邮件 | 自动领取邮件奖励 |
| 好友奖励 | 自动领取好友赠送奖励 |
| 普竞 | 自动完成普竞挑战 |
| 迷梦之域 | 自动挑战迷梦之域（可设置次数） |
| 女神塔 | 自动挑战女神塔 |
| 挂机奖励 | 自动领取挂机奖励（可设置付费次数） |
| 商城 | 自动购买友谊商城打折物品 |
| 日常任务 | 自动领取日常任务和公会任务奖励 |
| 爬塔 | 自动爬塔 |
| 幻灵推图 | 自动幻灵推图 |
| 推图 | 自动推图 |
| 循环推图 | 自动在幻灵推图和推图之间切换循环 |
| 异界迷宫 | 自动挑战迷宫 |

## 运行环境

- **操作系统**: Windows 10/11
- **游戏分辨率**: 1600*900
- **游戏模式**: 横屏

## 使用方法

### 1. 准备工作

右侧 release 下载最新版本。

确保文件夹结构如下：

```text
梅林初号机/
├── goldenhandmaidens.exe
├── shared/
├── game_bot_config.json         
├── warehouse_heroes.txt
└── game_bot.log
```
### 2. 运行程序
- **启动游戏并进入主界面。**

- **以管理员身份运行 goldenhandmaidens.exe。**

- **在界面中勾选需要执行的功能（第一次运行务必勾选仓库）。**

- **点击「开始运行」。**

### 3. 配置说明
- **登录**：处理开始游戏到登录后的月卡和礼包界面。

- **仓库管理**：推图以及爬塔需要最新仓库信息支持，默认为全部角色练度为巅峰+以上。自定义练度请按照种族、职业、推图常用英雄自己修改。

- **普竞**：挑战最左边玩家，默认使用完所有免费次数。

- **邮件**：自动领取全部邮件，需要囤积邮件请手动关闭。

- **迷梦之域**：可设置挑战次数。

- **女神塔**：默认用完普通徽记，不会使用精致徽记。

- **每日任务**：需要卡公会币上限请暂时关闭此功能。

- **挂机奖励**：可设置付费购买次数（0-2次）。

- **推图和爬塔**：推图会跳过手动作业，并且使用练度符合的阵容。练度只分为巅峰+及以上和巅峰+以下两种。

- **异界迷宫**：可以设置挑战次数，15/20层，小怪和最终 boss 阵容。

### 4.文件说明
- **文件/文件夹**	说明
```text
梅林初号机/
├── goldenhandmaidens.exe  主程序
├── shared/  程序运行时需要的文件夹（程序自动生成）
├── game_bot_config.json   配置文件（程序自动生成）      
├── warehouse_heroes.txt   仓库英雄记录（程序自动生成）
└── game_bot.log           本地持久化日志，用于查看和反馈问题
```

- **日志**：GUI 日志和控制台详细日志都会保存到 `game_bot.log`，可在程序中查看、刷新和清空。

### 5.注意事项
- **首次运行**：请务必运行一次仓库管理。

- **运行期间**：请勿移动鼠标或操作游戏窗口，保持游戏窗口最上方。

- **模板匹配**：如果识别失败，请检查游戏分辨率和界面是否正确。

- **停止运行**：点击「停止运行」按钮或关闭窗口。

- **其他问题**：遇到错误请在 Issue 反馈。

### 6.常见问题
Q: 程序启动后没有反应？

A: 请确保 shared 文件夹已创建，启动时需要当前界面可以看到玩法目录四个字，在其他界面无法顺利运行。

Q: 部分场合弹出礼包导致停止运行？

A: 手动退出到玩法目录界面，重新启动程序。

Q: 识别不到按钮？

A: 请检查游戏分辨率是否正确，界面是否与模板匹配。

Q: 如何停止正在运行的任务？

A: 点击界面上的「停止运行」按钮。

Q: 异界迷宫自动退出？
A: 请检查你使用阵容所需的角色是否已经准备好。

Q: 异界迷宫boss阵容缺失？

A: 主包不更新我也没办法，随便拿个阵容凑合用吧，支持催更若隐寒星和千秋月。
